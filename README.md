# Farely – Ride Fare Comparison Platform

Farely is a mobile-first ride fare comparison platform with a centralized wallet, developed as a Final Year Project (FYP).

## Problem Statement
Users in Pakistan rely on multiple ride-hailing apps (Careem, Yango, inDrive) to compare fares manually. Farely simplifies this by providing real-time fare comparison and a unified wallet experience.

## Key Features
- User authentication
- Ride fare comparison across providers
- Centralized wallet system
- Transaction history
- Mobile-first React Native application

## Tech Stack
### Frontend
- React Native (Expo)

### Backend
- Node.js
- Express.js
- MongoDB
