# Farely - Ride Aggregator Comparison Platform

Farely is a mobile-first ride aggregator for Final Year Project (FYP) defense: it compares estimated fares and redirects users to provider apps for final booking.

## Problem Statement
Users in Pakistan rely on multiple ride-hailing apps (Yango, inDrive, Careem) to compare fares manually. Farely simplifies this with a single comparison view of estimated fares and app redirection via deep links/fallback links.

## Key Features
- User authentication
- Estimated fare comparison across providers
- Deep-link based redirection to provider apps
- Admin web panel for search/selection/support monitoring
- Mobile-first React Native application
